# IoT Based Smart Streetlight System with Solar Panels and Batteries for Energy Efficiency. 

## Overview
This Final Year Project presents an IoT-enabled smart solar street lighting system with adaptive energy management and traffic-responsive control using ESP32.

The system optimizes energy consumption by adjusting streetlight brightness based on:
- Vehicle detection
- Vehicle speed classification
- Battery State of Charge (SoC)
- Environmental lighting conditions

## Features
- Adaptive brightness control
- Solar-powered operation
- ESP32-based control system
- Vehicle-responsive lighting
- Speed classification system
- Energy-saving modes
- Smart city application

## Hardware Components
•	ESP32 Microcontroller with Expansion Board
•	5V,0.23W Solar Panels
•	TP4056 Lithium Battery Charging Module with Protection.
•	3.7V 4000mAh 804060 Lithium Polymer (Li-Po) Rechargeable Battery
•	Ultrasonic Ranging Module (HC- SR04)
•	MT3608 DC–DC Step-Up (Boost) Converter
•	Super Bright White LED
•	Light Sensor Module 
•	Logic-Level N-Channel MOSFET (IRLZ44N)
•	Resistors (220 Ω and 1k Ω)
•	Real-Time Clock Module (DS3231) 
•	INA219 Voltage and Current Sensor
•	Breadboard, jumper wires, and supporting electronic modules

## Software Used
•	Arduino IDE
•	RemoteXY (IoT Platform) 
•	Microsoft Excel 

## Project Objectives
Objective 1:	To design and implement an IoT-based smart and predictive street lighting control mechanism using vehicle detection, real-time clock scheduling, adaptive LED brightness control, and inter-pole lighting coordination to optimise energy usage and enhance road safety.
Objective 2:	To analyse and evaluate the performance of the proposed system by monitoring real-time parameters such as lighting state, vehicle detection events, battery status, and energy savings through an IoT-based monitoring platform.
Objective 3:	To enhance system sustainability and operational reliability by integrating solar energy harvesting with battery storage and implementing battery-aware control strategies to extend battery lifespan and maximise solar energy utilisation.
